# Степені в задачі Ердеша №634

19 листопада 2026. Позначимо через T(N) існування хоча б одного невиродженого трикутника, який можна розбити на N конгруентних трикутників. Дозволяються відбиття й довільні T-стики. Тут і надалі основа й показник степеня — додатні цілі. Якщо в означенні задачі взято N>1, випадок N=1 просто пропускаємо.

## 1. Кожний п’ятий степінь допустимий

**Твердження.** Для всіх n та k≥4 виконується T(nᵏ).

**Використана теорема.** У рукописі Vico Bonfioli, розділ *Isosceles targets with base angles α+β*, теорема *Notch seed family* дає для взаємно простих 1≤e<f, b=f²−e² розбиття T(bt²) при всіх цілих t≥t₀. Сторони плитки дорівнюють (ef,b,f²), зовнішні сторони — (tbf,tbf,tbe). Точна достатня межа має вигляд

    h = ceil(e/(f−e)),  j = ceil(he/b),
    M = max(ceil(fh/e), h+ceil(eh/f)),  t₀ = fj+M.

У джерелі наведено окрему попередню конструкцію Denis Paliy для всіх достатньо великих масштабів фіксованої плитки. Тут потрібна саме кількісна межа. Текст декларації Bonfioli й означення функції порога звірено з версією вихідних файлів за посиланнями нижче. У цій сесії збірку Lean з нуля не виконано.

**Непарне n≥3.** Покладемо e=(n−1)/2 і f=e+1. Тоді b=n, h=e, j=ceil(e/2), M=2e. Остання рівність випливає з ceil(e²/(e+1))=e. А для j маємо e²/(2e+1)=e/2−e/(4e+2), де останній доданок строго між 0 та 1/4. Отже t₀=(e+1)ceil(e/2)+2e≤(e+1)e+2e≤(2e+1)²=n². Беремо t=n² і дістаємо bt²=n⁵.

**Парне n≥4.** Покладемо e=n−1 і f=n+1. Вони взаємно прості, оскільки обидва непарні й відрізняються на 2. Тепер b=4n, h=n/2, j=ceil((n−1)/8), M=n. Для останньої рівності маємо fh/e≤n та eh/f=n/2−n/(n+1), звідки h+ceil(eh/f)=n. Потрібно взяти t=n²/2. Для n≥6 виконується

    2t₀ ≤ (n+1)(n+6)/4 + 2n = (n²+15n+6)/4 ≤ n²,

де використано ceil((n−1)/8)≤(n+6)/8 та 3n²−15n−6≥0. Тепер bt²=4n(n²/2)²=n⁵. Для n=4 підійде звичайне квадратне розбиття на 32² частин, для n=2 — поділ рівнобедреного трикутника навпіл і подальше розбиття кожної половини на 4². Випадок n=1 тривіальний.

**Усі показники k≥4.** При парному k число nᵏ є квадратом. Для непарного k≥5 поділимо кожну з n⁵ плиток стандартною трикутною сіткою на (n^((k−5)/2))² однакових дрібних трикутників. Це доводить твердження.

## 2. Межі для проміжних масштабів

Та сама конструкція доводить більше. Для непарного d≥3 маємо T(dm²) при кожному m≥d+floor(d²/8). Дійсно, при e=(d−1)/2 парному достатній t₀=(e²+5e)/2. При непарному e≥3 короларій Bonfioli *Odd e* дає (e²+5e+2)/2. Для e=1 маємо t₀=4. Підстановка показує, що отриманий поріг дорівнює заявленому при непарному e і на один менший при парному e. Для парного d≥4 побудова з e=d−1, f=d+1 дає T(dm²) при кожному **парному** m≥2(d+1)ceil((d−1)/8)+2d. Ці межі достатні. Навіть для класичного d вони можуть бути істотно завищені.

**Куби добутків.** Нехай n=xy, де 3≤x<y непарні й взаємно прості. Якщо y≤4x²(x−2), то T(n³). Зокрема, достатньо y≤x³. Беремо e=(y−x)/2, f=(y+x)/2. Спільний дільник e,f ділить x,y, отже він дорівнює 1. Тут b=xy, h=ceil(e/x)≤e та h<f/x. Тому j<y/(4x²)+1, бо fe=(y²−x²)/4. Обидві складові M не більші від y: перша ≤f, друга ≤2e. Оскільки f≤y, то t₀<y²/(4x²)+2y≤xy=n. При t=n конструкція дає n³. Для x=19,y=43 одержуємо e=12,f=31,b=817,h=1,j=1,M=3,t₀=34. Таким чином існує розбиття на 817m² плиток при кожному m≥34.

## 3. Які прості степені лишаються

Для k=1 використовується класифікація простих у Beeson–Roșu, за якою допустимі 2, 3 та прості 1 mod 4. Усі квадратні кратні таких чисел також допустимі. Для простого p>3 з p=3 mod 4, що належить до класів 7, 11 чи 23 mod 24, допустимий p³:

* для 7,23 mod 24 знаходимо примітивне представлення p=2v²−u² з 0<u<v;
* для 11 mod 24 знаходимо примітивне представлення p=3v²−u² з 0<u<v.

Існування цих представлень — лема 5.1 записки Paliy про насичення квадратних класів, з посиланнями на нормові форми. Розбиття при масштабі t=p дає конструкція W для першого випадку й β для другого. Справді, в обох випадках запис p=Dv²−u²=(Dv−u)v+(v−u)u має D=2 або 3. Беремо вихідне розбиття масштабу v, збільшуємо його масштаб у Dv−u разів стандартною сіткою й додаємо v−u облямівок масштабу u. Це користується лише вихідним розбиттям і конкретним допустимим приростом; окремо той самий висновок дає теорема Paliy про всі масштаби t≥v. Кількість плиток p·p². Так вирішено всі прості степені, за єдиним класом можливих винятків — показник 3 та p=19 mod 24.

Для такого p число p³=19 mod 24. Геометричне зведення Paliy, розділ 5 *Without squarefreeness*, лишає тільки θ і рівнобедрений випадок подвійного кута. В обох b=v²−u² і p³=bt² при t≥2. Отже t=p, b=p, (v−u)(v+u)=p, звідки u=(p−1)/2, v=(p+1)/2. Маємо **дві** конкретні пари форм для кожного p. Наприклад, p=19 дає N=6859:

| Ціль | Плитка | Сторони цілі |
|---|---|---|
| θ | (90,19,100) | (3610,3610,3249) |
| Подвійний кут | (81,19,90) | (3249,3249,3610) |

**Перевірена межа методу.** У теоремі Bonfioli *Band theorem* для θ при f=e+1 умова (a) змушує n≥e і M≥f. Із (d) випливає k≥enf/(2e+1)≥e²(e+1)/(2e+1). При цільовому масштабі M+k=2e+1 мусило б бути k≤e, що неможливо для e≥2. Наприклад, для e=9 навіть ці дві умови вимагають M+k≥53, тоді як для 19³ потрібне 19. Це виключає саме цю форму застосування теореми про смугу. Існування обох геометричних розбиттів для 6859 залишається невизначеним у цій роботі.

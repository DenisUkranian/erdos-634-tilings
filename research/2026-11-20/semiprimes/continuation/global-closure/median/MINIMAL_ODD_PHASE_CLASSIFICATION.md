# All phases in the minimal odd-population case

21 November 2026. This is a necessary normal form for **every** complete
tiling of either target with total odd-height population `3c`. It is
not a three-cell spine assumption and does not exclude the minimal
case or decide either target. No search is performed here.

## 1. Inputs and notation

Put

\[
 R=\mathbb Z[\rho],\quad \rho=e^{i\pi/3},\quad
 z=(a+b\rho)/c,\quad
 A=b(2a+b),\quad B=a(a+2b).
\]

The standard board has vertices `0,A,B*rho`. The two targets have
`(a,b,c)=(33,7,37)` and `(35,13,43)`. Normalize the valuations at
the two Eisenstein primes above `c` by

\[
 v_\pi(z)=1,\quad v_{\bar\pi}(z)=-1,
 \quad v_\pi(c)=v_{\bar\pi}(c)=1.
\]

Children increase physical height in the `pi` tree and decrease it
in the conjugate tree. At short height `h`, exact nodes are the
cosets defined by valuations at least `h` and `-h`, respectively.
Every vertex belongs to `R[1/c]`.

The previously proved
[actual-median localization](../../charge-transport/geometry/ACTUAL_MEDIAN_CHARGES.md)
gives, under `n_odd=3c`:

* Only short heights `0,1,2` occur.
* All height-one tiles belong to `A+zR` in the standard frame.

In particular there is one occupied exact height-one node in each
tree. We also use the
[occupied-parent theorem](../../charge-transport/flux/SIGNED_CUT_TRANSPORT.md):
a nonempty exterior-free subtree on either target has an occupied
immediate parent. This statement refers to the actual full tiling.

## 2. The complete phase normal form

**Theorem.** Every tile of such a tiling has its obtuse vertex, and
hence all three vertices, in the corresponding set:

| Standard short height | Permitted vertex set |
|---:|---|
| 0 | `R+zR` |
| 1 | `A+zR` |
| 2 | `A+zR+z^2R` |

Equivalently, the allowed Euclidean classes are exactly the following
list of **permitted** classes; not every listed class must be occupied:

\[
\begin{array}{ll}
 h=0:& rz+R,\quad 0\le r<c,\\
 h=1:& A+zR,\\
 h=2:& A+rz+z^2R,\quad 0\le r<c.
\end{array}                                                   \tag{1}
\]

Thus there are `2c+1` permitted classes: **75 at 3431** and
**87 at 5063**.

### Height zero

If a height-zero node in the increasing tree were exterior-free,
its occupied parent would have height `-1`, which is absent.
It is therefore the exterior height-zero node, giving
`v_pi(q)>=0`.

In the decreasing tree, a free height-zero node must have the unique
occupied height-one node as its parent. A non-free height-zero node
is the core and already has that same parent. Hence in either case
`v_barpi(q-A)>=-1`, equivalently `v_barpi(q)>=-1`, since `A` is
integral. Together with integrality away from `c`, these are exactly
the conditions for `q in R+zR`.

### Height two

In the decreasing tree, a free height-two node would require an
occupied height-three parent, impossible. Its conjugate-prime node
is therefore the exterior one, so `v_barpi(q-A)>=-2`.

In the increasing tree, an exterior-free height-two node has the
unique occupied height-one parent. The non-free height-two node
also has this parent. Thus `v_pi(q-A)>=1`. The simultaneous
conditions are exactly `q-A in zR+z^2R`.

These fractional-ideal equalities follow by taking the minimum of
the two prime exponents in a sum: `R+zR` has exponents `(0,-1)`,
and `zR+z^2R` has `(1,-2)`. No other prime denominator occurs.
The short-edge vectors lie in `z^hR`, a subgroup of the displayed
set, so the same membership holds for all tile vertices.

Finally `(R+zR)/R` has order `c` and is generated by `z mod R`.
Likewise `(zR+z^2R)/z^2R` has order `c`, generated by `z mod z^2R`.
The representatives in (1) are therefore complete and distinct.

## 3. The isometry to the path frame

The established isometry is

\[
 F(x)=Bz^2-\rho z^2\overline{x}.
\]

It sends standard height `h` to path height `2-h` and sends `A`
to `c^2`. Since `Bz^2 in z^2R` and `c^2 in R intersect zR`, the
three sets transform to

| Path short height | Permitted vertex set |
|---:|---|
| 0 | `R+zR` |
| 1 | `zR` |
| 2 | `zR+z^2R` |

For example, the standard height-two set transforms to
`c^2+R+zR=R+zR`; the standard height-zero set transforms to
`Bz^2+z^2R+zR=zR+z^2R`. The middle set transforms to
`c^2+zR=zR`. Phase indices may be relabeled by this isometry;
only the positioned sets, not a fixed numerical labeling, are asserted
to be preserved.

## 4. The nonnative even classes are exactly the free terminal gates

Use the path frame and fresh representatives

\[
 L_r^-=rz+R\quad(h=0),\qquad
 L_r^+=rz+z^2R\quad(h=2),\qquad 0\le r<c.
\]

All height-zero tiles have the same non-free increasing-tree node.
Their `c` possible decreasing-tree nodes are precisely the children
of the unique height-one node. The class `L_0^-=R` contains the
base edge node; every `L_r^-` with `r!=0` is exterior-free.

Similarly, all height-two tiles have the same non-free conjugate-tree
node. Their `c` increasing-tree nodes are precisely the children of
the unique height-one node. Only `L_0^+=z^2R` contains exterior
height-two edges; the other classes are exterior-free.

Every occupied nonzero class is terminal in its corresponding tree:
its proper descendants have short height at most `-1` or at least
`3`, both absent. Conversely, these are all possible occupied
exterior-free nodes under the minimal-odd hypothesis. In particular,
the classes are actual exact-node populations, not an arbitrary
aggregation of Euclidean cosets.

The gate labels can be checked directly. Normalize the height-one
coordinates by dividing by `z`; let an actual long-edge beta endpoint
be `u=zU`, where `U=x+y*rho in R`. Put

\[
 \phi(U)=ay-bx\pmod c,\qquad
 \psi(U)=ax-by\pmod c.
\]

Then

\[
 u\in L_r^+\iff\phi(U)=-br\pmod c,
 \qquad
 u\in L_r^-\iff\psi(U)=ar\pmod c.                 \tag{2}
\]

Both are bijective labelings of the `c` gates, since `a,b` are units
modulo `c`. In particular the two native gates are exactly residue
zero. The other endpoint belongs to the same gate because its long
vector belongs to the relevant height lattice.

For a nonzero occupied class let its charge be `G_r=c*g_r`. Signed
ordinary-node divisibility makes `g_r` an integer. If `Q_r` is the
signed number of height-one parent tiles whose long edge uses this
gate, the terminal transport identity gives

\[
 \boxed{Q_r=(a-b)g_r\qquad(r\ne0).}                 \tag{3}
\]

The same equality has both sides zero for an empty class. At an empty
gate, the equal-length bank argument additionally forces every crossing
height-one tile into its full half-turn pair. An occupied balanced
class may instead have `g_r=0` with genuine unmatched contacts; zero
charge must not be identified with an empty gate. The native residue
zero has exterior terms and is not covered by (3).

## 5. What this reduction provides

Every permitted vertex belongs to `c^(-2)R`, and the board is bounded.
There are therefore finitely many contained placements in these
`2c+1` classes, with no guessed coordinate radius or phase cutoff.
A full endpoint model for this entire mode would also impose the
exact count `n_1=3c`. The complete geometric sufficiency argument is
the same positive-current argument used for the smaller
[spine model](../spine/NATIVE_ENDPOINT_COMPLETENESS.md).

The additional nonzero even classes are essential: the three-cell
spine model does not cover them. This note classifies all of them and
identifies their physical gates, but supplies no infeasibility result,
positive tiling, or new search. Both target questions remain open.

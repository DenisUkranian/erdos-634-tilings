# A finite search on the 3431 board with varying staircase depths

Fix the (33,7,37) tile. We tested 1,512 parameter records for placements obtained from staircase blocks in the original unit board, including signed rises, reverse advances, and changes of scaffold depth. The same inventory can occur more than once. No record in this list admits a complete tiling. This tests only the listed placements; an additional placement can change the conclusion.

The board uses axial coordinates multiplied by 37. For each record the generator emits unit grids from the [staircase construction](https://github.com/DenisUkranian/erdos-634-tilings/blob/ea420d780718a9e4a1801dfcb66c8f8975e48863/research/2026-11-20/semiprimes/staircase/STAIRCASE.md). Oversized bands contribute their full positive grid. Negative triangle scales use the half-turn, and rectangles contribute cells when both dimensions have the same nonzero sign. For reversed or folded steps this is a list of proposed placements; there is no assumption that the blocks form a geometric partition. Only full unit triangles contained in the board enter an inventory, with coincident placements merged.

The first 74 records have one to four steps with strictly positive rises summing to 4 and intermediate depths from 0 through 6. Another 224 vary two signed steps with initial and final depths one. Another 357 change the two endpoint depths, including depth two at the base. The last 857 have three signed steps and include reversals. The complete ranges, congruences and filters are specified by the generator.

**Exact rejection test.** Give each retained triangle a binary selection variable and orient its boundary counterclockwise. For each primitive line direction and endpoint assign +1 at the start of an oriented parallel side and −1 at its end. A full tiling must give the boundary data of the outer triangle. Subdividing an edge at a T-junction cancels its new endpoint contributions, so the test does not require edge-to-edge contacts. For each endpoint equation compute the integer minimum and maximum over the still unassigned variables. If the right-hand side equals one extreme, every incident unassigned variable is forced. A demand outside this interval certifies impossibility. The method also applies when a vertex of the outer triangle has no permitted placement. The checker tests a satisfiable one-triangle inventory and an empty inventory as controls.

Run `python3 folded_inventories.py 4` with Python 3.10 or later. The optional argument selects the number of processes. The script regenerates each inventory and verifies its endpoint contradiction using integer arithmetic. It writes no placement files.

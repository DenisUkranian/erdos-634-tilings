# Independent audit: every multiplier of ordered F3 when a<b

The proposed construction passes this independent symbolic audit. It
uses two already proved positive constructions, namely
[F4 for a<b](../../group2-f4/PROOF.md) and the
[smaller ideal trapezoid](../../group2-trapezoids/PROOF.md). No conclusion
about the opposite F3 order is obtained by changing the names of a and
b, since that changes the target.

## Statement

For positive integers `a<b` and `c^2=a^2+ab+b^2`, the triangle with sides

```
c^2, c(a+2b), 3b(a+b)
```

can be tiled by `3(a+b)(a+2b)` congruent copies of the tile with sides
`a,b,c`. Consequently, scaling the target by any positive integer m
and subdividing each enlarged tile gives
`3(a+b)(a+2b)m^2` unit tiles. Primitivity is not needed for these
positive constructions.

## 1. Exact coordinates and macro shapes

Use Eisenstein coordinates with metric `x^2+xy+y^2`, and set
`A=ab`, `B=b^2`. Put

```
X=(-a^2,0), Y=(2A,-2A-B), K=(2A,A+2B),
Q=(A,-A), E=(2A,-2A), L=(A,A+B), R=(2A,A+B).
```

The target is XYK. Its side lengths are

```
|XY|=c^2, |XK|=c(a+2b), |YK|=3b(a+b).
```

For example, `K-X=(a+2b)(a,b)`, and the squared norm of
`Y-X=(a(a+2b),-b(2a+b))` is `(a^2+ab+b^2)^2`.

The five pieces are as follows.

| Piece | Audited side lengths or shape | Unit count |
|---|---|---:|
| XYQ | ac,bc,c^2: c-fold original tile | c^2 |
| YQE | ab,b^2,bc: b-fold original tile | b^2 |
| LRK | ab,b^2,bc: b-fold original tile | b^2 |
| XQL | ac,c(a+b),b(2a+b): ordered F4(a,b) | (2a+b)(a+b) |
| EQLR | ideal trapezoid, short base 2ab+b^2 and leg ab | 5ab+2b^2 |

In particular, the F4 block has precisely the order `a<b` for which
the existing F4 proof applies. No reversed-F4 statement is imported.

For the trapezoid, the explicit isometry

```
f(x,y)=(x+y,2A-x)
```

is a translation followed by multiplication by `rho^(-1)`. It sends

```
(E,R,L,Q) -> ((0,0),(3A+B,0),(2A+B,A),(0,A)),
```

which is exactly the standard ideal trapezoid T(2A+B,A).

## 2. Positive partition, including all ratio ranges

The macro partition itself is valid for all positive a,b. L lies
strictly inside side XK because

```
L-X=(a+b)(a,b), K-X=(a+2b)(a,b).
```

E and R lie in this order strictly inside side YK. Q lies strictly
inside XYK: its inward cross products against XY,YK,KX are

```
ab*c^2, 3ab^2(a+b), ab(a+2b)(2a+b),
```

all positive. Here the determinant is in Eisenstein coordinates, whose
positive physical conversion factor is irrelevant to the signs.

Draw XQ, YQ, and QL. This divides XYK into XYQ, XQL, and the convex
quadrilateral YQLK. In the latter quadrilateral, drawing QE and LR
cuts off the triangles YQE and LRK. The remaining region is EQLR.
These two cuts do not cross: their y-coordinate ranges are
`[-2A,-A]` and `{A+B}`, respectively. All five regions have positive
area. This proves containment, coverage, and disjoint interiors by a
planar dissection, rather than by area alone.

## 3. The trapezoid hypothesis is satisfied

Let `d=a+b-c`. The norm equation gives `0<d<min(a,b)`. The established
trapezoid theorem constructs T(s,ab), with

```
s=a^2+b^2-ad=b^2-ab+ac,
```

and also T(x,ab) whenever `x-s` belongs to the nonnegative integer
semigroup generated by a,b. For `x=2ab+b^2`,

```
x-s=a(3b-c).
```

Because a<b, `c<a+b<2b`; hence `3b-c>b>0` is an integer. The displayed
gap is the explicit semigroup representation consisting of `3b-c`
copies of a. Its associated rectangular strip is a genuine grid
filling. No arbitrary real scale or signed piece is used.

The trapezoid tile count also follows directly from its area:
its coordinate area is `ab*(2x+ab)/2`, whereas a unit tile has
coordinate area `ab/2`. Thus its count is `2x+ab=5ab+2b^2`.

## 4. Count and scope

Adding the five established fillings gives

```
c^2+2b^2+(2a+b)(a+b)+5ab+2b^2
 =3a^2+9ab+6b^2
 =3(a+b)(a+2b).
```

Every gluing interface is a complete macropolygon boundary. Unit
subdivisions on opposite sides may differ, producing allowed
T-junctions. This does not affect the positive macro partition.

The result is a complete sufficient construction at every integer
multiplier for this ordered F3 sector. It does not settle all F3
orders, all norm branches, or all N in Erdős problem 634. The former
hexagon obstruction belongs to a different proposed partition and
does not apply to this construction.

The accompanying `check_f3_a_lt_b_audit.py` independently verifies
exact macro containment, pairwise separation, side lengths, areas,
the trapezoid isometry, and the explicit semigroup expression on a
finite primitive sample. The algebra and planar dissection above,
not that finite sample, prove the universal statement.

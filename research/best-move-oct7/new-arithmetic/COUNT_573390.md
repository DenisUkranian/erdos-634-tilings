## 2. Every possible realization must use F3

The exact factorization is

```
N=2 * 3² * 5 * 23 * 277.
```

The last factor is prime, as trial division through 16 verifies. Also
`N=14 (mod 16)` and `v_5(N)=1`. The established
[F3 isolation theorem](../../../docs/f3-global-overlap.md), which uses the
complete necessary spectra, therefore excludes every branch other than
F3. Its inputs do not include the proposed all-primes theorem.

This conclusion concerns any congruent-triangle realization, including
alternative tiles and targets.

## 3. Unique ordered primitive tile and residual multiplier

Write the necessary primitive F3 form as

```
N=3(a+b)(a+2b)m²,
gcd(a,b)=1, c²=a²+ab+b², m>=1.
```

The factorization permits only `m=1` or `m=3`. The latter would give
`N/m²=63710`, which is not divisible by three. Hence `m=1`.

Put `s=a+b`, `t=a+2b`. Positivity of a and b gives

```
st=191130=690*277,   s<t<2s,
a=2s-t, b=t-s,
c²=t²-3st+3s².
```

The inequalities imply `310<=s<=437`, since

```
2*309² < 191130 < 2*310²,
437² < 191130 < 438².
```

If `277|s`, this range would force `s>=554`, a contradiction. Therefore
`s|690`. For `310<=s<=437`, the integer `690/s` lies strictly between
one and three, so it must be two. Thus

```
s=345, t=554, a=136, b=209, c=301.
```

The pair is coprime. This proves that the displayed ordered primitive
tile is the only possible one in any classified realization of N.
Swapping a and b gives a different F3 coefficient; it is not an
additional realization of this same N.

## 5. An explicit infinite F3-only positive family

For every integer `k>=0`, put

```
p=15+1650k,
a=8(p+2), b=p²-16, c=p²+4p+16,
N(p)=6p(p+8)(p²+4p-8).
```

Then N(p) is an actual tiling count, and every realization belongs to F3.
Moreover, `11` does not divide N(p), so these counts cannot be obtained
by integer subdivision of the earlier 990-tile seed.

Here is a direct arithmetic verification. Expanding gives the norm
equation and `N(p)=3(a+b)(a+2b)`. Since p is odd,

```
gcd(a,b)=gcd(8(p+2),p²-16)=gcd(p+2,12)=1:
```

the second argument is odd, and `p=0 (mod 3)` makes p+2 coprime to
three. For `p>=15`, `a<b`, so the new all-multiplier ordered-F3 theorem
applies at multiplier one. The factors of N(p) are positive and strictly
increase with p, giving infinitely many distinct counts.

For odd p the side a is 8 modulo 16, while b is either 1 or 9 modulo
16. In either case `3(a+b)(a+2b)=14 (mod 16)`. Also
`p=15 (mod 25)` gives `v_5(p)=1`; the other two factors p+8 and
`p²+4p-8` are nonzero modulo five. Thus `v_5(N(p))=1`, and the F3-only
theorem applies to every member. Finally p is 4 modulo eleven, so

```
N(p)=6*4*1*2=4 (mod 11).
```

The first member is p=15 and N=573390. One may omit the exclusion of
990-subdivisions and use the larger progression `p=15+150k` instead.

For this particular displayed tile, the old nested-corner test fails
throughout the progression: in descending short-side labels its width is

```
ac-b²=-p(p³-8p²-80p-192).
```

Writing `q=p-15>=0`, the cubic in parentheses is
`q³+37q²+355q+183>0`. Hence that width is negative. However, uniqueness
of the primitive F3 candidate has been proved here only for p=15. The
family statement does not assert that every later member was absent from
all prior project constructions, nor that it has only one candidate tile.

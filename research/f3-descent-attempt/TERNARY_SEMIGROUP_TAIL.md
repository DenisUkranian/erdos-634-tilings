# A uniform multiplier-one cone from the three-generator corner theorem

**Research directed by Denis Paliy, with ChatGPT assistance — 6 October 2026.**

The [nested-corner theorem](../group2-nested-corners/PROOF.md) constructs
the reversed F4, F2 and both F3 orientations at multiplier one whenever
the primitive integer 120-degree tile satisfies

    a>b>0,  c²=a²+ab+b²,
    bc−a² ∈ <a,b,c>.                                    (1)

Here the semigroup uses nonnegative integer coefficients. This note gives
a uniform arithmetic sufficient condition for (1), and hence infinitely
many additional complete fixed-tile multiplier spectra. It does not
classify all F3 tiles or all counts in Erdős problem 634.

## 1. A constructive conductor bound

Write the positive rational number `(a+c)/b` in lowest terms as `m/n`.
Then `m>n>0`, and

    mb−nc=na,    mc−nb=(m+n)a.                           (2)

The first identity is the definition; the second follows from
`c²=a²+ab+b²`, or by multiplying out after substituting `mb=n(a+c)`.

**Lemma.** Every integer

    x ≥ (m+n−2)(b+c)                                    (3)

belongs to `<a,b,c>`.

**Proof.** The two integer vectors

    v₁=(m,−n),    v₂=(−n,m)

preserve the residue of `Bb+Cc` modulo a, by (2), and are linearly
independent. Every residue modulo a has some integer representative
`Bb+Cc`, since `gcd(a,b)=1`. Start with the residue
`x−(n−1)(b+c)`. Reduce one such integer pair `(B,C)` modulo the sublattice
generated by v₁,v₂ into its half-open fundamental parallelogram.
The resulting pair has the form `λv₁+μv₂`, `0≤λ,μ<1`, and both integer
coordinates lie in `[-n+1,m−1]`. Add n−1 to each coordinate. The final
pair, denoted `(B',C')`, satisfies

    0≤B',C'≤m+n−2,
    B'b+C'c ≡ x (mod a).

Its value is at most the right side of (3). Therefore
`A=(x−B'b−C'c)/a` is a nonnegative integer, giving the required
representation. The sublattice need not be the entire residue kernel;
surjectivity before reduction is sufficient. This point also covers the
factor-three primitive normalization below. □

An explicit algorithm needs no search. Put `H=m+n−2`,
`B₀=((x−(n−1)(b+c))b⁻¹) mod a`, and `D=m²−n²`. Set

    u=floor(mB₀/D),    v=floor(nB₀/D),
    B=B₀−mu+nv+n−1,
    C=nu−mv+n−1,
    A=(x−Bb−Cc)/a.

For x satisfying (3), these coefficients are nonnegative and verify
`x=Aa+Bb+Cc`. The accompanying script implements and replays this formula.

**Construction consequence.** Every primitive tile with a>b and

    bc−a² ≥ (m+n−2)(b+c)                                (4)

has the multiplier-one targets in the nested-corner theorem. Ordinary
quadratic subdivision then gives **every positive integer multiplier**
for the same fixed tile and each of those target shapes.

## 2. Uniform cones of primitive tiles

Let `r=a/b`, `s=c/b=√(r²+r+1)`, and `q=m/n=r+s`. The usual primitive
parameterization follows directly from the norm equation:

    a=(m²−n²)/g,
    b=n(2m+n)/g,
    c=(m²+mn+n²)/g,    g∈{1,3}.                         (5)

For completeness, the unnormalized expressions have common divisor only
1 or 3. Any common odd prime divides `2m+n` and `m²−n²`, hence divides 3;
2 is excluded by parity and coprimality of m,n. When 3 divides the triple,
the valuation of `m²+mn+n²` at 3 is exactly one. Normalization therefore
gives exactly (5).

Define ρ_* as the unique positive root of

    R³−R²−1=0,    ρ_*≈1.46557.

For every fixed `1<R<ρ_*`, put

    s_R=√(R²+R+1),    q_R=R+s_R,
    ε_R=s_R−R²>0,
    K_R=√3 (q_R+1)/√(2q_R+1).

**Theorem.** If a primitive tile satisfies

    1<a/b≤R,
    sqrt(b) ≥ K_R(1+s_R)/ε_R,                            (6)

then it satisfies (4), and hence has every positive integer multiplier
in reversed F4, F2 and both F3 orientations.

**Proof.** On r≥1, `√(r²+r+1)−r²` is strictly decreasing. Thus

    bc−a² = b²(s−r²) ≥ ε_R b².

From (5),

    (m+n)² = g b (q+1)²/(2q+1) ≤ K_R² b,

because `(q+1)²/(2q+1)` increases for positive q and `g≤3`.
Also `b+c≤(1+s_R)b`. Consequently

    (m+n−2)(b+c) < K_R(1+s_R)b^(3/2).

Condition (6) makes this smaller than `bc−a²`, proving (4).
The root defining ρ_* is the boundary `√(R²+R+1)=R²`, since
`R⁴−R²−R−1=(R+1)(R³−R²−1)`. □

The result is uniform over every primitive tile in the stated cone;
it is not a numerical scan extrapolated to larger side lengths.

## 3. A simple explicit numerical range

In particular,

    1<a/b≤7/5,    b≥4900                               (7)

is sufficient. Indeed, `s<21/10`, `q<7/2`, and

    s−r² ≥ (5√109−49)/25 > 1/8.

Furthermore

    (m+n)² ≤ (243/32)b < (196/25)b,

so `m+n<(14/5)√b`. Therefore

    (m+n−2)(b+c) < (217/25)b^(3/2) = 8.68 b^(3/2),
    bc−a² > b²/8 ≥ 8.75 b^(3/2)       when b≥4900.

This proves (4). The number 4900 is a convenient sufficient cutoff,
not an optimal one.

### Removing the size cutoff by a complete finite certificate

**Theorem. Every primitive integer 120-degree tile with `1<a/b≤7/5`
has multiplier-one tilings in reversed F4, F2 and both F3 orientations,
and consequently has every positive integer multiplier in those shapes.**

It remains only to cover `b<4900`. In this range (5) and `q>1` imply
`b=n²(2q+1)/g>n²`, hence `1≤n<70`. The angle bound gives `q<7/2`,
so `m<245`. Thus the following finite enumeration is exhaustive:

    1≤n<70,    n<m<245,    gcd(m,n)=1,

followed by primitive normalization (5) and retention of precisely
`a>b`, `5a≤7b`, `b<4900`. It returns **240** distinct triples.
The [240-witness certificate](../group2-nested-corners/balanced-7-5-small-witnesses.json)
gives explicit nonnegative integers `(A,B,s)` for every one, verifying

    bc−a²=Aa+Bb+sc.

All 240 therefore satisfy the already proved geometric criterion (1).
The [read-only checker](../group2-nested-corners/check_balanced_7_5_small.py)
regenerates the complete parameter list and independently enumerates
side pairs `1≤b<4900`, `b<a≤floor(7b/5)`, retaining coprime pairs whose
norm is a square. The two lists agree, and every saved identity passes.
A separate internal replay implemented the direct side enumeration anew
and independently checked the same 240 stored identities and set equality.
Combining this complete bounded certificate with Section 3's infinite
tail proves the stated theorem without a size qualification.

The clean earlier corner theorem `c≤2b` already covers every scale for
`1<a/b≤(√13−1)/2≈1.30278`, with no size restriction. The present cone
extends multiplier-one existence beyond that angle range: the entire
range through `7/5` is now covered, and every closed subinterval below
ρ_* is covered for sufficiently large primitive tiles. The individual
semigroup test can succeed below the uniform cutoff:
for `(88,65,133)`,

    bc−a²=901=5a+3b+2c,

although `c>2b`.

## 4. Limits and reproducibility

For `a/b≥ρ_*`, the remainder `bc−a²` is nonpositive (and equality cannot
occur for positive integers). Thus this construction criterion supplies
no multiplier-one tiling there. **This is a limitation of the construction,
not a nonexistence theorem.** In particular, the fixed F3 candidate
`(24,11,31)` at count 4830 remains outside this argument.

Run `python semigroup_tail.py` from this directory, or
`python research/f3-descent-attempt/semigroup_tail.py` from the repository
root. The script checks the explicit residue representative algorithm
for all coprime parameters `1≤n<m≤40` and every residue modulo the
associated primitive a. It also prints two larger exact witnesses,
including factor-three normalization. Default execution is read-only;
`--report PATH` writes the deterministic JSON report.

The finite replay tests the explicit arithmetic algorithm; the lattice
argument and inequalities prove the infinite claims. The positive
geometry is the separately verified nested-corner construction. No
external priority or referee acceptance is claimed.

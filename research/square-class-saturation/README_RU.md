# Эрдёш №634: конструктивное заполнение квадратных классов

**Денис Палий. Исследование с помощью ChatGPT. 1 октября 2026 года.**

## Что сделано

Вместо очередного усиления отрицательного фильтра получен конструктивный результат для целых квадратных классов. Для двух арифметически заданных коллекций квадратсвободных ядер d построена одна плитка, которая реализует все числа dm² при m≥2d. Есть более точный, явно вычисляемый порог. В секторе d≡14 (mod16), 3∤dm, m нечётно это соединяется с прежним исключением остальных ветвей и даёт двусторонний критерий для каждого большого множителя.

Полная задача №634 не решена. Малые множители и остальные классы не объявляются ни допустимыми, ни невозможными. N=154 этим ходом не решён. Внешней рецензии, формальной проверки универсального доказательства и установленного первенства нет.

## 1. Основная конструктивная теорема

Пусть d>2 свободно от квадратов. Если каждый нечётный простой делитель d равен 1 или 7 по модулю8, то

\[
\boxed{dm^2\in\mathcal S\quad\text{для каждого целого }m\ge2d.}
\]

Здесь S означает существование хотя бы одной плитки и одного треугольника, разбиваемого на указанное число конгруэнтных плиток. Отражения и T-соединения разрешены.

Для каждого такого d эффективно находятся взаимно простые 0<u<v с

\[
d=2v^2-u^2.
\]

Плитка имеет стороны

\[
(uv,\ v^2-u^2,\ v^2),
\]

а большой W-треугольник — стороны

\[
m(v^3,\ ud,\ v(v^2-u^2)).
\]

Плитка и форма цели фиксируются один раз по d; затем конструкция работает для всех достаточно больших m, включая нечётные и не кратные3.

Арифметический критерий представимости через 2v²−u² уже есть у Бисона, Lemmas44–45. Стартовое разбиение и мотив добавляемого слоя также существовали. Здесь выведен точный порог для заполнения слоя полосами, доказана линейная оценка через d и записана единая конечная конструкция для каждого большого множителя. Эти ранее известные части не выдаются за новые открытия.

## 2. Точный критерий на целом секторе

Пусть

\[
d\text{ квадратсвободно},\quad d\equiv14\pmod{16},\quad3\nmid d,
\qquad \gcd(m,6)=1.
\]

Для каждого m≥2d:

\[
\boxed{dm^2\in\mathcal S
\iff
\text{все нечётные }p\mid d\text{ равны }1\text{ или }7\pmod8.}
\]

Если условие на простые нарушено, невозможность верна для всех m, взаимно простых с6, без нижней границы. Если оно выполнено, конструкция даёт все m выше более точного вычисляемого порога, даже без ограничения gcd(m,6)=1.

Причина полноты отрицательной стороны: прежняя таблица необходимых спектров, основанная на опубликованной классификации, оставляет при N≡14 (mod16), 3∤N только ветвь W. В ней простой квадратичный невычет для2 не может входить в квадратсвободное ядро. Это прежнее препятствие; новый шаг — совпадающая с ним конструктивная сторона для всего хвоста класса.

Например, для d=110 нечётные простые5 и11 нарушают условие. Поэтому 110m² невозможно при gcd(m,6)=1. Условие на m нельзя убрать: этот модуль намеренно не применяет отрицательный тест к 990=110·3².

## 3. Реальный порог часто меньше 2d

Обозначим

\[
a=uv,\quad b=v^2-u^2,\quad c=v^2,\quad Q=b+c,\quad P=b+2c.
\]

Вычисляем

\[
R=\lceil c/b\rceil,\qquad
H=\left\lceil\frac{b+c(R-1)}u\right\rceil,
\]

\[
C(u,v)=v\lceil H/v\rceil+(u-1)(v-1).
\]

Доказано: каждый масштаб m≥C существует в обеих формах W и beta, причём

\[
\boxed{C(u,v)<2Q<2P.}
\]

Это достаточный порог, не утверждение о минимальном числе плиток.

| Ядро и форма | Параметры | Плитка | Достаточный m |
|---|---|---|---:|
| d=14, W | u=2,v=3 | (6,5,9) | m≥11 |
| d=46, W | u=2,v=5 | (10,21,25) | m≥29 |
| d=62, W | u=6,v=7 | (42,13,49) | m≥58 |
| d=94, W | u=2,v=7 | (14,45,49) | m≥55 |
| d=142, W | u=10,v=11 | (110,21,121) | m≥156 |
| d=122, beta | u=5,v=7 | (35,24,49) | m≥52 |

Для d=14,m=11 получается N=1694, плитка (6,5,9), цель со сторонами (297,308,165). Конструкция начинает с масштаба9 и добавляет один слой ширины u=2. Геометрический сертификат состоит из11 выпуклых блоков с точными целочисленными правилами заполнения. Новизна самого числа1694 не утверждается.

## 4. Почему слой теперь заполняется на всех нужных масштабах

В прежнем геометрическом слое остаётся параллелограмм с длинами bc и

\[
L=ubT-a^2-b^2.
\]

Его заполняют полосы двух типов, если L=xb+yc для неотрицательных целых x,y. Вместо грубой достаточной оценки через Фробениуса решено именно это уравнение.

Из gcd(b,c)=1 следует y≡−c (modb). Наименьшее допустимое y и соответствующее x:

\[
y=bR-c,\qquad x=uT-b-c(R-1).
\]

Другие допустимые y только уменьшают x. Поэтому данный способ заполнения работает тогда и только тогда, когда T≥H. Это эквивалентность для способа заполнения полосами, а не необходимая граница для всех возможных мозаик.

Стартовое разбиение существует на каждом масштабе, кратном v. Для любого m≥C выбирается единственное 0≤i<v с iu≡m (modv). Число m−iu — допустимый стартовый масштаб не меньше H. Далее добавляются i слоёв ширины u. Это всегда меньше v добавлений.

Доказательство C<2Q использует H≤Q и

\[
C\le H+uv-u\le Q+uv-u<2Q.
\]

Так переход от фиксированной плитки к классу d становится количественным: арифметика сначала выбирает плитку с Q=d, после чего известная геометрия даёт весь хвост с единым порогом2d.

## 5. Второе конструктивное семейство

Аналогичная теорема работает для

\[
d=3v^2-u^2
\]

и beta-равнобедренной цели. Для квадратсвободного d, кроме вырожденных случаев2 и3, точный арифметический тест представимости следующий: каждый простой p>3, делящий d, равен1 или11 по модулю12; дополнительно d≡2 (mod3), когда3∤d, и d/3≡1 (mod3), когда3|d.

При этих условиях все dm² с m≥2d конструктивно допустимы. В полном доказательстве записана элементарная проверка знака нормы и приведение к0<u<v; не предполагается, что одних локальных тестов достаточно без этого доказательства.

Например, d=122 не проходит W-тест из-за простого61, но проходит beta-тест. Получены все122m² при m≥52, в частности N=342698 при m=53. Это положительный результат для класса, который W-теорема не покрывает.

## 6. Проверки и файлы

`run_checks.py` выполнен со стандартными настройками. Проверены:

* все12160 квадратсвободных ядер d≤20000: два арифметических теста сопоставлены с независимо написанным прямым перечислением параметров;
* 1965 примитивных пар при v≤80, 212741 план построения и745 прямых проверок точного порога полос;
* 193 полных сжатых геометрических сертификата:3527 блоков и60568 пар блоков; наибольший представленный размер —12079899 плиток;
* отклонение7 испорченных сертификатов и5 некорректных входов.

Проверяющий код не импортирует генератор и не полагается на историю поиска. Он проверяет точные длины сторон каждой ячейки, нахождение блоков внутри цели, площади, число плиток и отсутствие пересечений внутренностей всех пар блоков. Все вычисления рациональные. Отдельные миллионы плиток не перечислялись: проверены конечные схемы сеток, которые их задают. Эти конечные тесты не заменяют универсальное доказательство.

Запуск:

```bash
python run_checks.py
python saturation.py 1694 38686 215822 342698 13310 154
python saturation.py 1694 --certificates output
```

YES означает конструкцию; NO — применённый с полными условиями отрицательный критерий; UNKNOWN — отсутствие ответа именно этого модуля. Например,154 получает UNKNOWN. Это дополнительный модуль, а не замена прежним программам и не отмена ранее известных конструкций.

Главное доказательство: `PROOF.md`. Полные отчёты: `verification.json`. Примеры геометрии: `examples/`. Необходимая предыдущая заметка сохранена без изменений в `dependencies/`.

Новый положительный аргумент не опирается на спорный кандидат для всех простых, на леммы о длинных швах или на доказательство нулевой плотности. Но он также не доказывает минимальность C и не решает оставшиеся малые масштабы. «Конечное число исключений в каждом классе» не превращается в одну конечную таблицу для всей задачи. GitHub и письма этим пакетом не изменялись.

# The 54-tile mixed parallelogram route to the primitive F3 count 990

**Status of this 54-tile parallelogram: INCOMPLETE.** There is no complete
tiling certificate or proved impossibility for the parallelogram studied
here. A later [nested-corner construction](../group2-nested-corners/PROOF.md)
does construct **990** by a different positive partition, with a fully
checked 990-tile certificate. Thus this unresolved auxiliary parallelogram
is no longer a barrier to that count. Erdős problem 634 remains unresolved.
The exploratory search programs are not retained as certified repository
machinery.

## Exact sufficient reduction

Take the primitive 120-degree tile with sides `(a,b,c)=(8,7,13)`.
Let `rho=exp(i*pi/3)` and use coordinates `x+y*rho`. Consider the
60-degree parallelogram

```
P = [(0,0), (56,0), (56,27), (0,27)].
```

Its area is `56*27*sqrt(3)/2`, while a tile has area `14*sqrt(3)`.
Thus a tiling of P would have exactly **54** tiles.

**A tiling of P would construct the primitive F3 count 990.** This follows
from the already proved positive partitions in
[BALANCED_F4.md](../group2-trapezoids/BALANCED_F4.md); no extension of the
existing strip-filling claim is assumed. Here is the precise missing piece.
In the free-width corner partition put `m=k=1`, `t=a-b=1`, and
`z=(8+7*rho)/13`. The vertices are

```
F=(0,0), O=(8,0), A=(169,0), B=(64,56), C=(8,7),
E=(104,0), D=(112,7),
U=(616/13,539/13), V=(1672/13,280/13).
```

The quadrilateral `Q=OABC` is the 13-fold tile triangle `FAB` with
the reflected unit triangle `FOC` removed, and needs `169-1=168` tiles.
The existing positive partition of Q consists of:

| Piece | Established filling | Count |
|---|---|---:|
| `OEDC` | 13-by-1 two-tile parallelogram grid with one corner tile removed | 25 |
| `CDU` | 8-fold triangular grid | 64 |
| `EAV` | 5-fold triangular grid | 25 |
| `UDVB` | The currently missing filling of P | 54 |

Indeed `e=(15-8*rho)/13` has norm one and `e*rho=z`; the isometry

```
w -> U + e*w
```

maps the four listed vertices of P to `U,D,V,B`, respectively. The
high parallelogram is therefore exactly P, up to a proper rigid motion.
Its previously required short-strip width is
`bc-a^2=91-64=27`, which is not in the semigroup generated by 8 and 7.
Replacing just that missing strip filling by any genuine tiling of P
would complete the same geometric partition.

The proved reflection bridge then adds two 13-fold triangular grids,
giving the F2 triangle with sides `(169,176,161)` and count
`168+2*169=506`. Its proved F3 attachment adds a 22-fold triangular grid,
giving sides `(169,286,315)` and count `506+22^2=990`.
The same Q filling would also give reversed F4 with count
`168+2*8^2+7^2=345`.

This is a **sufficient route**, not an equivalence. Even a proof that P
cannot be tiled would only eliminate this particular corner-transfer
construction. It would not prove that 990 is impossible.

## Finite boundary information and the search outcome

Each length-27 boundary side has the unique multiset of whole tile edges
`{7,7,13}`. On a length-56 side the possible edge-count triples, in the
order `(number of 8-edges, number of 7-edges, number of 13-edges)`, are

```
(7,0,0), (0,8,0), (1,5,1), (2,2,2).
```

An exact rational enumeration gave 260 possible boundary triangle
placements and 6,022 conflicting pairs with overlapping interiors.
Coverage of all four boundary sides and the necessary alpha-plus-beta
fan at each 60-degree corner admit a 16-tile boundary collar. Consequently
these boundary constraints alone give no contradiction. This is a partial
placement, not a tiling of P.

An exploratory advancing-front search from that particular collar
visited 311 states without a completion. A separate run from the empty
target reached a 37-tile partial placement before its 60-second limit
(3,100 visited states); an angle-filtered run also stopped at its
90-second limit (4,600 states). A further exploratory run using the
available direction-height population restrictions stopped after 60.7
seconds, with 3,300 states and the same deepest partial count 37.
These timeouts are not exhaustive
nonexistence checks. The search implementation and its state enumeration
have not received an independent completeness audit, so even the first
collar's failed search is not used as a published negative certificate.

The experiment uses exact rational containment and triangle-intersection
checks, with integral seam lengths for pruning. Neither a deep partial
placement nor the existence of a feasible boundary collar establishes
extendibility. No complete 54-tile certificate has been produced.

## Why the pure-island bound does not close this target

The existing
[pure-region theorem](../../docs/nonconvex-pure-island-reduction.md)
proves `2*c^2 | N` for a pure region whose boundary uses only long-edge
directions, even when that region is nonconvex. For this tile the
divisibility is `338 | N`. The stronger minimum `2*a*b*c^2` is proved
only for **convex pure** regions.

An arbitrary filling of P need not be pure: its boundary can use both
short and long tile edges, and internal extreme-height components can
also be mixed. Thus neither `54 < 338` nor the larger convex minimum
rules out a filling of P. Applying the convex minimum to an unknown
nonconvex component would likewise be invalid.

The outstanding obligation is an actual positive filling of this mixed
54-tile core, or a separately justified obstruction covering every such
filling. Neither has been obtained in this attempt.

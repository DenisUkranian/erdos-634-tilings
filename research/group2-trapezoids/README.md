# Positive trapezoid and reflected-corner surgery

The [proof](PROOF.md) gives universal smaller ideal-trapezoid seeds for a
primitive 120-degree integer tile, a wider parameterized seed family,
an explicit counterexample to a proposed two-seed necessary spectrum,
and a scaled reflected-corner construction. The companion
[corner-transfer proof](BALANCED_F4.md) allows the rectangle width to vary
independently and supplies every multiplier at least two in reversed F4,
F2, and F3 when `a>b` and `3c>=4a`.

More generally, it constructs all three target families whenever an
integer `k>=1` satisfies `kc>=m(a-b)` and `mbc-a²k` belongs to the
nonnegative integer semigroup generated by `a,b`. For primitive triples,
this criterion is equivalent to
`a ceil(m(a-b)/c) <= b floor(mc/a)`. It never passes at primitive
multiplier one; this is a limitation of the construction, not an
impossibility theorem for arbitrary tilings.

The principal universal seeds are

```
T(a²+b²−b(a+b−c),ab),
T(a²+b²−a(a+b−c),ab).
```

This improves the clean sufficient equilateral tail to
`m>=3 ceil(c/min(a,b))`. The general shaving family sometimes improves
that tail further. These are positive constructions, not a full spectrum
or an arbitrary-island normal form.

The companion's independently checked full F4 examples are recorded in
`balanced_f4_verification.json` and `free_k_verification.json`; their
expanded unit-coordinate certificates are kept alongside the smaller
macrocertificates. The free-width checks include `(5,3,7)` at multipliers
2 and 3, which the original fixed-width condition cannot construct.

All code is original standard-library Python. It has no dependency on an
upstream search engine or source tiling certificate. The generator and
checker share rational polygon primitives, but the checker does not
import the generator or reconstruct its formulas: it checks the supplied
macroregions and their explicit positive subdivision recipes.

Run the frozen finite campaign:

```
python check_family.py
python check_balanced_f4.py
python check_target_bridges.py
python check_free_k.py
```

Generate and check an individual certificate:

```
python generate.py 3 5 7 example.json
python verify.py example.json --expand
python generate.py 32 45 67 counterexample.json --shave 12
python verify.py counterexample.json
python generate.py 7 8 13 beta_corner.json --shave 1 --multiplier 2 --kind corner
python verify.py beta_corner.json
python construct_free_k.py 5 3 7 2 --output f4_example.json
python verify_reversed.py f4_example.json
python construct_free_k.py 5 3 7 2 --family F2 --output f2_example.json
python verify_f2.py f2_example.json
```

`--expand` checks every unit tile and every pair of unit tiles. Without
it, positive unit tilings follow from verified integer triangle grids,
short-edge strips, and a rectangular b,c grid with a triangular corner
removed. Every macroregion pair is checked in either mode.

[VERIFIED_RESULTS.json](VERIFIED_RESULTS.json) records the exact replay
scope. The fixed 6458-tile counterexample and the scaled corner examples
are checked as macrocertificates; their unit pairs were not expanded in
this package's frozen campaign. Two small seeds are expanded in full.

The `(3,5,7)` positive one-leg bases were already recorded by Harries.
Here they follow from a symbolic construction, not an imported search
certificate. The negative bases retain their outside proof dependency.
No claim of priority or external acceptance is made.

# Задача Эрдёша №634 — кандидат для простых чисел и точные разбиения

**Денис Палий · исследовательская версия v0.1.0 · 29 сентября 2026 года**

[English](README.md) · [Статус утверждений](STATUS.md) · [Воспроизведение](REPRODUCIBILITY.md)

Главный результат этой работы — **кандидат на доказательство классификации всех простых чисел плиток**. Отдельно получена явная конструкция из **322 конгруэнтных треугольников** и доказан полный спектр чисел плиток для одного рационального семейства форм. Полная [задача Эрдёша №634](https://www.erdosproblems.com/634) в этой работе ещё не решена.

## Кандидат для всех простых чисел

Предлагаемое утверждение: для простого $p$ существует треугольник, который можно разбить на $p$ конгруэнтных треугольников, тогда и только тогда, когда

$$
p=2,\qquad p=3,\qquad\text{или}\qquad p\equiv1\pmod4.
$$

Новые геометрические аргументы исключают две формы при минимальном масштабе для плиток с $3\alpha+2\beta=\pi$: разностороннюю $W=(2\alpha,\beta,\alpha+\beta)$ и равнобедренную $(\beta,3\alpha,\beta)$. Совместно с указанными результатами классификации это дало бы утверждение для всех простых $p$.

**Статус: цельный кандидат, требующий внешней математической проверки.** Особого внимания требуют вынужденное выделение треугольного блока и завершение столбцов. Внутренние проверки проведены; компьютерное воспроизведение конечного разбиения не доказывает эти общие геометрические шаги.

Основной текст — [полная рукопись кандидата для всех простых чисел](paper/prime-case-candidate.pdf): два новых геометрических аргумента, исчерпывающая таблица случаев, расчёты для остальных ветвей и явные конструкции существования. Дополнительные материалы: [геометрический рабочий текст](docs/prime-case-candidate.md) и [внешние зависимости и переход к классификации](docs/prime-case-dependencies.md).

## Конструкция 322 и общее семейство

Для фиксированной примитивной плитки

$$
(a,b,c)=(uv,v^2-u^2,v^2),\qquad 0<u<v,\quad\gcd(u,v)=1
$$

треугольник формы $(2\alpha,\alpha,2\beta)$ допускает ровно следующие числа плиток:

$$
N=k^2(2v^2-u^2)(3v^2-u^2),\qquad k\ge1.
$$

Доказательство склеивает известную конструкцию Бисона со стандартным треугольным блоком. Оно не зависит от кандидатов на доказательство невозможности других разбиений.

При $(u,v)=(2,3)$ склейка треугольников $(84,45,81)$ и $(84,70,126)$ по стороне $84$ даёт треугольник $(81,115,126)$, разбитый на $126+196=322$ плитки со сторонами $(6,5,9)$.

![Точное разбиение на 322 плитки](figures/tiling-322.png)

[Доказательство и рисунок, 2 страницы](paper/two-piece-construction.pdf) · [Полные координаты и общий аргумент](docs/two-piece-construction.md)

Отдельная реализация проверяет точные координаты всех плиток, их конгруэнтность, покрытие, **51 681 пару** на отсутствие перекрытия положительной площади и согласованность рёбер, включая **24 Т-стыка**. Это независимая реализация внутри проекта, а не внешняя рецензия.

## Дополнительное продвижение

| Результат | Точный охват |
|---|---|
| [Структура масштабов](docs/scale-spectra.md) | Для каждой примитивной плитки допустимые масштабы форм $W$ и $\beta$ с некоторого места — в точности кратные некоторого $d\mid v$. Новая конструкция доказывает $d=1$ при $\Delta=b(a^2+b^2)-a^2c>0$. Дополнительный диапазон параметров и малые исключения ещё не классифицированы. |
| [Все пять рациональных форм при $\Delta>0$](docs/eventual-rational-families.md) | Построены все достаточно большие арифметически допустимые масштабы с явной границей. Необходимые формы $N=bT^2$ для формы $\theta$ и $N=b(b+c)K^2$ для формы $\alpha$ доказаны для всех примитивных плиток этого семейства, без ограничения $\Delta>0$. |
| [Известные спектры первой плитки](docs/scale-spectra.md) | Для $(2,3,4)$ числа $7t^2$ в форме $W$ и $11t^2$ в форме $\beta$ допустимы ровно при $t\ge2$. Эти результаты принадлежат Bonfioli; их новизна здесь не заявляется. |
| [Равнобедренная форма $\theta=\alpha+\beta$](docs/theta-branch.md) | Для плитки $(2,3,4)$ получен точный спектр **$N=3t^2$ для всех целых $t\ge4$**. Новое разбиение на 75 плиток закрывает последний масштаб $t=5$. Для любой примитивной рациональной плитки семейства $3\alpha+2\beta=\pi$ два инварианта направлений дают необходимый вид $N=bT^2$ с целым $T$. |

Конструкции на 75, 147 и 243 плитки прошли отдельную точную проверку пересечений и согласованности границ. Наименьший пример также опровергает утверждение об интегральности параметра $\mu$ в лемме 55 версии v4 Бисона: здесь $\mu=15/2$ и число раскраски $M=5$. Кандидат для простых чисел эту лемму не использует. Это не завершает классификацию остальных плиток и форм.

Само число 75 было глобально допустимо и раньше. Новое разбиение закрывает конкретный случай: треугольник $(30,30,15)$ и 75 копий плитки $(2,3,4)$, завершая этот фиксированный спектр. Для $N=105$ [аргумент об одном внутреннем угле](docs/n105-fixed-collar-obstructions.md) исключает продолжение двух построенных граничных полос. Он не исключает другие полосы; ни существование, ни общая невозможность 105-разбиения здесь не доказаны.
